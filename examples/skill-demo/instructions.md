# Release note skill — authored acceptance demo

Produce one concise Markdown release note in `release.md`.

Required rules:
1. Start with `# Release note`.
2. Include a `## Changes` section.
3. Include a `## Risks` section; say explicitly when no known risks remain.
4. In the human-review variant, a person must confirm that the language is useful
   for the intended audience. No script can establish this subjective judgment.

The companion contract defines the exact criteria for this demo. It does not
claim to translate arbitrary prose into complete machine verification.
